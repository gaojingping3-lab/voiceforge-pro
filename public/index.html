使用说明

快速开始

  1. 点右上角 齿轮 ⚙️，填好大模型 API Key（DeepSeek）
  2. 在「文本转语音」页顶部填好 Fish API 密钥 和 模型ID（克隆声音ID）
  3. 切到「AI语音对话」页，发消息即可，AI 回复后自动用克隆声音朗读

文本转语音

  • 引擎选择：支持 Fish Audio（推荐）、硅基流动、阿里云
  • 模型ID：填你的克隆声音ID，留空用默认音色
  • 语速：0.5~2.0 可调，1.0 为正常速度
  • 格式：MP3（推荐）、WAV、Opus
  • 合成后可直接播放或下载 MP3 文件
  • 历史记录自动保存最近 15 条

AI 语音对话

  • AI 角色叫"乐"，可在设置里自定义角色设定（System Prompt）
  • AI 回复后自动用你的克隆声音朗读
  • 大模型默认 DeepSeek，可在设置里切换其他 OpenAI 兼容接口
  • 对话记录不保存，刷新页面即清空

声音ID生成

  • 上传 10~30 秒清晰的人声音频
  • 填写参考文本（音频里说的话）
  • 提交后获得声音ID，复制到「文本转语音」页使用
  • 支持 Fish Audio 和硅基流动两个平台

API Key 获取

  • DeepSeek：platform.deepseek.com（大模型，按token计费）
  • Fish Audio：fish.audio（语音合成，按字符计费）
  • 硅基流动：cloud.siliconflow.cn（国内平台，新用户有免费额度）

常见问题

Q: 显示"Load failed"？
A: 网络波动，自动重试一次。频繁出现请换网络或关VPN。

Q: 显示"401 Incorrect API key"？
A: API Key 填错或过期，重新复制完整的 Key。

Q: 声音不像克隆的？
A: 确认模型ID填对了，克隆音频要清晰无背景噪音。

Q: 配置会丢失吗？
A: 所有配置保存在你手机浏览器本地，清除缓存才会丢失。
